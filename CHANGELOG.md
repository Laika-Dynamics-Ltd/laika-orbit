# Changelog

## 0.1.0: first public preview

- **The map:** every indexed file, repo, chat and routine as a 3D ring.
- **Claude panel:** Claude Code chats in split groups or a 2×2 grid, per repo or project folder,
  several accounts at once, task track and sub-agent cards, automatic recovery after a crash or
  restart, and duplicate chats closed for you.
- **Browser:** Chromium tabs with one storage profile per account, Chrome-style tabs, and Chrome
  extensions from the Web Store.
- **Widgets:** Gmail inbox, iCal calendar, agents, routines and skills.
- **Laika Orbit recall:** zero-model recall engine, CLI and MCP server.
